# Tomato Dataset Attribution and License

The tomato image archive in `dataset/tomato_dataset.zip` is organized from the PlantVillage tomato leaf disease images into `train`, `validation`, and `test` splits. The class names and image naming match the PlantVillage dataset.

The dataset page maintained by the original PlantVillage authors identifies the dataset license as **Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)**: [PlantVillage dataset card](https://huggingface.co/datasets/mohanty/PlantVillage). The original dataset repository is [spMohanty/PlantVillage-Dataset](https://github.com/spMohanty/PlantVillage-Dataset). This archive is redistributed with attribution and under the same CC BY-SA 3.0 terms.

Please cite the dataset paper:

> Mohanty, S. P., Hughes, D. P., & Salathé, M. (2016). Using deep learning for image-based plant disease detection. *Frontiers in Plant Science*, 7, 1419. https://doi.org/10.3389/fpls.2016.01419
